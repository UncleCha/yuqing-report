# Reports archive

This folder stores published HTML reports.

Recommended structure:

```text
reports/
  index.html
  yyyy-mm-dd-report-slug/
    index.html
```

Public URL pattern:

```text
https://unclecha.github.io/yuqing-report/reports/yyyy-mm-dd-report-slug/
```

Keep the repository root `index.html` as the current report entry when an existing shared link must continue working.
